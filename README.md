## 📱 Cara Memainkan di HP (Android & iOS)

### 1. Membuka di Browser HP
1. **Tautan Resmi Game:** Buka link berikut di browser HP Anda (Google Chrome di Android atau Safari di iPhone):
   👉 **`https://shinfort.github.io/Petualangan-Yaya-dan-Caca/`**  
   *(Jika link belum aktif, aktifkan terlebih dahulu di repositori GitHub lewat menu **Settings > Pages > Branch: main > Save**).*
2. **Masuk ke Game:** Pada menu utama beranda, tekan tombol hijau **"🎮 Mainkan Sekarang"**.
3. **Posisikan Layar Mendatar (Landscape):**
   * Aktifkan fitur **Rotasi Layar Otomatis (Auto-Rotate)** pada bar notifikasi HP Anda.
   * Miringkan HP ke posisi mendatar/tidur (*landscape*) agar seluruh slide dan tombol interaktif memenuhi layar.
4. **Mengaktifkan Suara / Dubbing:**
   * Pada browser HP, ketuk layar game atau tombol play sekali untuk mengizinkan pemutaran audio narasi Yaya dan Caca secara lancar.

### 2. Memasang Aplikasi ke Layar Utama HP (PWA / Tanpa Jaringan)

Dengan cara ini, game akan menjadi seperti aplikasi mandiri di HP Anda — tanpa perlu download dari Play Store / App Store.

**Untuk HP Android (Google Chrome):**
1. Buka link `https://shinfort.github.io/Petualangan-Yaya-dan-Caca/` di **Google Chrome**.
2. Tunggu hingga halaman beranda game selesai dimuat.
3. Ketuk ikon **⋮ (titik tiga)** di pojok kanan atas Chrome.
4. Pilih **"Tambahkan ke layar utama"** atau **"Install aplikasi"**.
5. Ketuk **"Tambahkan"** pada dialog konfirmasi yang muncul.
6. Ikon 🎮 **Yaya & Caca** akan muncul di layar utama HP Anda, bisa dibuka seperti aplikasi biasa.

**Untuk iPhone / iPad (Safari):**
1. Buka link `https://shinfort.github.io/Petualangan-Yaya-dan-Caca/` di **Safari** (bukan Chrome).
2. Ketuk ikon **Bagikan** (⬆️ kotak dengan panah ke atas) di bagian bawah layar.
3. Gulir ke bawah, lalu pilih **"Tambahkan ke Layar Utama"**.
4. Ketuk **"Tambahkan"** di pojok kanan atas.
5. Ikon game akan muncul di layar utama iPhone/iPad Anda.

**Setelah terpasang:**
* Buka aplikasi game dari layar utama → tekan **"📥 Unduh Mode Offline Lengkap"** sekali saja saat terhubung Wi-Fi.
* Setelah unduhan selesai 100%, game dapat dimainkan **kapan saja tanpa kuota internet** — bahkan dalam Mode Pesawat!

## 💻 Cara Memainkan di Laptop / Komputer

### Pilihan 1: Melalui GitHub Pages (Online / Browser)
* Langsung buka link GitHub Pages di Chrome atau Edge.
* Klik ikon install di kolom alamat (URL bar) untuk memasang game sebagai aplikasi desktop laptop.

### Pilihan 2: Secara Offline Langsung dari Laptop (Tanpa Internet)
* Klik dua kali file `Play.bat`.
* Browser laptop Anda akan otomatis membuka game di `http://localhost:8000` dan siap dimainkan secara offline 100%!

---

## 📶 Fitur Mode Offline (Tanpa Gangguan Jaringan)

Game ini dilengkapi dengan **Service Worker (PWA)**:
* **Penyimpanan Otomatis (Cache-on-play):** Setiap slide, animasi GIF, dan suara yang diputar akan otomatis tersimpan di perangkat Anda.
* **Unduh Offline Sekali Klik:** Di menu utama (`index.html`), terdapat tombol **"📥 Unduh Mode Offline Lengkap"**. Tekan tombol ini sekali saja saat tersambung Wi-Fi, dan seluruh isi game (25 slide beserta seluruh media) akan tersimpan di perangkat sehingga game dapat dimainkan di mana saja tanpa kuota internet.
